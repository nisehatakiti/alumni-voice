# AlumniVoice

AlumniVoice is an official extension plugin for Alumni Core.

## Current scope

- Requires Alumni Core Extension API 1.0+
- Registers the `alumni_voice` custom post type
- Structured alumni profile data
  - Full name and furigana (non-public)
  - Graduation year and Alumni Core-derived graduation term
  - Class/group
  - Contact email (non-public)
  - Public display name
  - Job taxonomy
  - Career/destination taxonomy
  - School destination
  - Workplace
- Alumni Core admin integration and hub page

## Not included

NHK Form integration and public submission forms are intentionally outside this plugin's scope. NHK Form is responsible for external form input and draft generation.

## Roadmap

1. Front-end search and filtering
2. Search facets for graduation year, job, career and destination
3. Group/archive views
4. Alumni directory person linkage
